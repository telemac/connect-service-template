# 0001 — Protobuf is the source of truth for entities

- Status: accepted
- Date: 2026-10-08

## Context

Entities must have a single definition that serves TypeScript frontends,
internal Go services, public REST clients and AI agents. Two candidates were
evaluated in [intent §5](../intent.md#5-options-for-the-source-of-truth):
proto-first with Connect v2, and Go-first with Huma v2.

## Decision

Entities are defined in `.proto` files under `api/`, with constraints declared
through protovalidate. Services run on `connectrpc.com/connect/v2`. REST is
served by Vanguard (`vanguard.Mount`) from the same `connect.Server`, and the
OpenAPI document is generated by `protoc-gen-connect-openapi`.

## Consequences

- Contract types are generated; domain types are hand-written Go with explicit
  mappers.
- `buf` becomes a required tool; generated code is not committed.
- Vanguard has no Connect v2 release yet: pin a `main` commit and move to the
  first tagged release.
- If public REST becomes the dominant consumer, revisit with Huma v2 as the
  fallback.
